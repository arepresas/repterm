# Agent instructions

## Git and GitHub

- Never merge anything. Do not merge pull requests, branches, tags, or changes into another branch.
- Do not run `gh pr merge`, `git merge`, `git pull` that integrates changes, or any equivalent command.
- Creating or updating a pull request is allowed only when explicitly requested. Merging still requires a separate, explicit instruction.
- This rule overrides any prior convenience, admin override, or implied next step.
